# explain/v1

2026-09-22. The first version, written from Document 4, Prompt 3: Explain.

**Text**: the prompt of the document, placeholder for placeholder: the decision object in its own data section with
the audience and the language as attributes, and the five numbered instructions. The system prompt is the shared
conduct alone. The rule set is not sent; the decision object carries no row id, so the same trace is one cached
explanation in every sandbox.

**Two settings changed from the document on the first live run, Document 4 first**:

- No temperature, not 0.3: the fast model refused 0.3 ("only the default (1) value is supported").
- Output cap 4,000 tokens, not 800: the three explanations spent 658 to 707 output tokens each.

**Measured** (2026-09-22): one live run on `gpt-5.6-luna`, recorded in `fixtures/eval/recordings/openai/explain/v1/`:
case 17 to an officer and to an applicant, and case 2 (approved, flagged for the stable-income check) to an officer,
7.4 to 8.9 seconds each, about 3,000 input tokens. Case 17 cites R-010, R-020 and R-330 with paragraphs 5, 6 and 7;
case 2 lists STABLE_INCOME_MANUAL_CHECK as a condition. Nothing was dropped by the trace checks.
