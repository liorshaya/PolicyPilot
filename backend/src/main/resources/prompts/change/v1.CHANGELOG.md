# change/v1

2026-09-24. The first version, written from Document 4, Prompt 5: Change.

**Text**: the prompt of the document, placeholder for placeholder, with instruction 1 as Document 4 has it since day
12: replace or remove only the candidate rules, never change the defaults, and remove a rule only when the request
names it by its id or by a value its condition tests. Those are the three refusals of the proposal validator
(Document 3, Patch validation), so the prompt says what the validator holds. The system prompt is the shared conduct
alone.

**Rendering**: the fields, the defaults and the candidate rules are compact JSON, one per line, the candidates in
evaluation order (priority, then id), so the prompt does not depend on how close two similarities were.
`{changeRequestId}` is `cr-` and the first eight hex digits of the SHA-256 of the request, so the same request on the
same version renders the same prompt in every sandbox and the response cache serves the scripted one; the stored
request's id replaces it in every pending provenance.

**Settings**: the model's own temperature, which is the only one the strong model accepts; Document 4's 6,000 tokens
and 60 s, until a live run shows them short.
