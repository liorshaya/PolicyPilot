# PolicyPilot | חבילת מיתוג מסודרת

פתחו את PREVIEW.png לתצוגת גרסאות המותג.

| תיקייה | מה יש בה |
|---|---|
| 01-Logos | לוגו מלא אופקי, לוגו אנכי והשם בלבד |
| 02-Symbols | הסמל ללא השם, בארבעה צבעים |
| 03-Favicon | favicon.ico, גרסאות SVG ו־PNG, וחלופה שקופה |
| 04-App-Icons | אייקוני Apple ו־Android, גרסאות maskable וקובץ manifest |

## מה לבחור

- לוגו לאתר בהיר: 01-Logos/Horizontal/policypilot-horizontal-navy.svg
- לוגו לאתר כהה: 01-Logos/Horizontal/policypilot-horizontal-white.svg
- תמונה רגילה במקום SVG: קובץ PNG בעל אותו שם.
- favicon ראשי: 03-Favicon/favicon.ico. סמל לבן על ריבוע כחול, מתאים לטאבים בהירים וכהים.
- favicon חלופי: 03-Favicon/favicon-transparent.ico. סמל כחול על רקע שקוף, מתאים בעיקר לטאב בהיר.
- שיתוף קישור: 05-Social/og-image.png, בגודל 1200×630.
- תמונת פרופיל: 05-Social/profile-square.png, בגודל 1080×1080, עם מרווח סביב הסמל לחיתוך עגול.

## צבעים ופורמטים

navy = כחול דיו #142C43, blue = כחול #285A80, white = לבן, black = שחור, two-tone = סמל כחול ושם בכחול דיו.

SVG הוא וקטורי וניתן להגדיל אותו ללא איבוד חדות. כל האותיות בלוגו הן צורות, ללא תלות בפונט. PNG הוא קובץ תמונה. כל הלוגואים והסמלים שקופים; הלוגו הלבן מיועד לרקע כהה.

לוגו אופקי ושם בלבד: PNG ברוחב 2400 פיקסלים. אופקי זמין גם ברוחב 800 בקבצים עם הסיומת 800. לוגו אנכי: רוחב 1600. סמל: 1024×1024.

## שילוב באתר Vite

1. העתיקו את favicon.ico ואת favicon.svg מתוך 03-Favicon לתיקיית public בפרויקט.
2. העתיקו את תוכן 04-App-Icons לתיקיית public, אם רוצים אייקוני מובייל ו־manifest.
3. העתיקו את og-image.png מתוך 05-Social לתיקיית public.
4. בחרו לוגו מתוך 01-Logos והעתיקו אותו ל־public בשם logo.svg.
5. הוסיפו את התגיות שב־06-Setup/head-snippet.html ל־head. עדכנו את הדומיין ב־og:image אם הוא שונה. אם אינכם משתמשים ב־manifest ובאייקוני מובייל, השמיטו את התגיות שלהם.

```tsx
<img src="/logo.svg" alt="PolicyPilot" width={180} style={{ height: 'auto' }} />
```

הנתיבים מניחים פריסה בשורש הדומיין. בפריסה בתת־תיקייה יש להתאים את הנתיבים ואת scope, id ו־start_url ב־manifest. ה־manifest אינו מוסיף בעצמו יכולות אופליין.

לבחירת favicon שקוף, השתמשו בזוג favicon-transparent.ico ו־favicon-transparent.svg יחד ושנו את שמותיהם ל־favicon.ico ו־favicon.svg בפרויקט. אחרת SVG עשוי להמשיך להציג את הגרסה עם הרקע.
